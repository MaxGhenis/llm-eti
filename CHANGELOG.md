# Changelog

## 0.2.0 - 2026-07-09

- Rebuilt the manuscript around the archived multi-model response corpus.
- Removed unsupported PKNF replication and hard-coded factorial-survey claims.
- Reconstructed prompt-delivered incomes and integer marginal tax rates.
- Added conservative duplicate handling, complete-case analysis, clustered
  inference, boundary-response reporting, and sensitivity checks.
- Replaced placeholder and fallback artifacts with one deterministic publication
  pipeline.
- Added Python 3.13 and NumPy 2 support, tests, secure CI, citation metadata, and
  explicit provenance documentation.
- Pinned Pillow 12.3.0 and FontTools 4.63.0, verified as the current PyPI
  releases on 2026-07-09, to remove known vulnerabilities from the old lock.
- Replaced the Jupyter Book and hand-maintained TeX paths with a Quarto
  microsite, native web paper, compiled PDF, and retained TeX from one source.
